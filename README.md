# Bike Sales Excel Dashboard Project

## Project Overview
This project involves creating a comprehensive and interactive Excel dashboard for analyzing bike sales. It utilizes techniques such as data cleaning, pivot tables, and visualizations to provide actionable insights based on customer demographics and sales trends.

## Tools Used
- **Microsoft Excel**

## Dataset
- **Dataset Used**: [Bike Buyers 1000 Dataset](https://www.kaggle.com/datasets/heeraldedhia/bike-buyers)

## Key Steps in the Project
1. **Data Cleaning**:
   - Removed duplicates and standardized categorical data (e.g., marital status, gender).
2. **Create Working Sheet**:
   - Created a copy of the raw data for manipulation, ensuring the original dataset remains intact.
3. **Pivot Tables**:
   - Used pivot tables to summarize and analyze data for creating visualizations.
4. **Visualizations**:
   - Built charts to represent insights such as average income, commute distance, and age brackets.
5. **Dashboard Creation**:
   - Consolidated visualizations into a single, user-friendly dashboard sheet.
6. **Chart Customization**:
   - Customized chart titles, axis labels, and formatting for enhanced clarity.

## Dashboard Components
- **Average Income by Gender and Bike Purchase**:
  - Analyzes average income by gender and bike purchase status.
- **Customer Commute Distance**:
  - Explores the distribution of customers by commute distance and bike purchase status.
- **Customer Age Brackets**:
  - Categorizes bike sales by age groups: adolescent, middle-aged, and old.
